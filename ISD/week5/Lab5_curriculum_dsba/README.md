# Lab5 — Curriculum Books (DSBA 2565)

งานส่วน **Curriculum books** ของ Lab5 (ISD / Chapter 5) — แมปหน้าเล่มหลักสูตรเข้ากับ ground truth
พร้อมชุดคำถาม–คำตอบที่อ้างอิงหน้าและข้อของข้อบังคับ

## หลักสูตรที่ทำ
- **หลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาวิทยาการข้อมูลและการวิเคราะห์เชิงธุรกิจ (DSBA)** — หลักสูตรปรับปรุง พ.ศ. 2565
- คณะเทคโนโลยีสารสนเทศ สจล.
- ต้นฉบับ: `../DataAndBusiness_c2565.pdf` (มคอ.2, 406 หน้า)

## ไฟล์ CSV — คำอธิบายคอลัมน์ (`csv/dsba2565_mapping.csv`)
| คอลัมน์ | ความหมาย |
|---|---|
| `gt_name` | ชื่อ/รหัสของ ground truth (หัวข้อข้อมูล) |
| `program` | หลักสูตรที่ข้อมูลนั้นอยู่ (DSBA) |
| `source_pages` | เอาข้อมูลมาจากหน้าใดของเล่มหลักสูตร |
| `question` | คำถามที่หาคำตอบได้จาก ground truth |
| `answer` | คำตอบ |
| `answer_page` | หน้าที่เป็นแหล่งข้อมูลของคำตอบ |
| `regulation_clause` | ข้อของข้อบังคับ (ถ้ามี) เช่น ข้อ 25, ข้อ 19.3 |

## หมายเหตุเรื่องเลขหน้า
เลขหน้าทุกที่ในไฟล์เหล่านี้ = **เลขหน้าที่พิมพ์บนเอกสาร มคอ.2**
เปิดจากไฟล์ PDF จริงให้ **บวก 5** → `หน้าใน PDF = หน้าที่พิมพ์ + 5`
(เช่น "หน้า 1" ของ มคอ.2 = หน้า 6 ในไฟล์ PDF)

## แหล่งอ้างอิงข้อบังคับ
คำถามหมวดเกรด/สำเร็จการศึกษา/เกียรตินิยม อ้างอิง
**ข้อบังคับ สจล. ว่าด้วยการศึกษาระดับปริญญาตรี พ.ศ. 2564** (ภาคผนวก ก, เริ่มหน้าพิมพ์ 85)

## สถิติ
- Ground truth: 5 หมวดหลัก + ชุดข้อบังคับ พ.ศ. 2564
- คำถาม–คำตอบ: **27 ข้อ** (12 ข้อมูลทั่วไป, 7 โครงสร้างหลักสูตร, 8 ข้อบังคับ/เกณฑ์)
